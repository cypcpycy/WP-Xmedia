管理歌曲资料。WordPress 插件连接独立部署的远程音乐 API，完成 QQ 音乐搜索、授权、试听和资源解析；媒体文件仍由 WordPress 导入自己的媒体库。

歌曲编辑页右侧的“搜索歌曲资料”面板支持 QQ 扫码登录、四档音质、在线试听和一键添加到音乐库。导入时会自动保存音频、封面与 LRC 歌词附件，并填写歌曲名、作者、专辑、时长和来源地址。

远程封面、授权音频和歌词文件可在保存歌曲时通过 WordPress 官方媒体接口自动导入媒体库，歌曲记录保存附件 ID，并优先使用本地附件地址。

后台设置可控制默认自动导入与封面、音频、歌词文件容量上限；歌曲编辑页也可以直接从 WordPress 媒体库选择文件。

歌曲添加与编辑使用精简专用界面，不显示 Gutenberg 正文编辑器，只保留必要的歌曲资料、分类和保存操作。

在文章或页面的区块编辑器中添加“音乐播放器”区块，即可从下拉列表直接选择音乐库歌曲，无需查找 ID 或手写短代码。

音乐库单曲详情页会自动显示当前歌曲播放器，点击歌曲链接后可直接播放，无需在歌曲正文中额外插入短代码。

== 使用方法 ==
1. 部署随项目提供的音乐 API 服务；本地可使用 Docker，云端也可部署到独立服务器。
2. 上传并启用 WordPress 插件，在“音乐库 > 设置”导入 JSON 接口规则文件；也可手动填写远程音乐 API 地址。
3. 进入“音乐库 > 添加歌曲”，首次使用时完成 QQ 扫码授权。QQ 登录状态保存在远程 API 服务器，与浏览器无关。
4. 选择音质并搜索；可试听、导入单曲，或点击专辑名称查看并批量导入整张专辑。
5. 整张专辑导入时会自动建立同名播放列表。也可在“音乐库 > 音乐播放列表”自行创建列表并给歌曲分组。
6. 使用 [music id="歌曲ID"] 插入单曲、[music_list limit="10"] 显示最新歌曲，或使用 [music_playlist id="列表ID"] / [music_playlist name="列表名称"] 插入整张播放列表。

播放器使用随插件分发的 APlayer 1.10.1（MIT License），不会在访客浏览页面时请求 CDN。歌曲标题、作者、封面、本地媒体附件与 LRC 歌词均会传入播放器；同一页面可放置多个 [music] 和 [music_list] 实例。[music] 可使用 lyrics="no" 关闭歌词。
